# Image Recognition System

## Project Overview
This project is a basic Image Recognition System developed using Python and OpenCV. It uses a pre-trained Haar Cascade classifier to detect human faces in an image. The detected faces are highlighted with green rectangles, and the total number of faces is displayed.

## Features
- Detects human faces in an image.
- Uses a pre-trained Haar Cascade model.
- Draws rectangles around detected faces.
- Displays the total number of faces detected.
- Shows the processed image in a new window.

## Technologies Used
- Python 3.14
- OpenCV
- NumPy

## How to Run

1. Install the required libraries:
```
pip install opencv-python numpy
```

2. Place an image named `sample.jpg` in the project folder.

3. Run the program:
```
python imagerecognization.py
```

## Expected Output
- The program detects human faces in the image.
- Green rectangles are drawn around each detected face.
- The total number of detected faces is displayed in the terminal.
- The processed image opens in a new window.
